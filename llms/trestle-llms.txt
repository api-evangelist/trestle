# Trestle (CoreLogic / Cotality)

> Trestle is the real estate data distribution platform operated by Cotality (formerly CoreLogic), sitting between roughly 500 US Multiple Listing Services and the technology providers, brokers and aggregators that consume their listing data. It maps each participating MLS into the RESO Data Dictionary 2.0 and republishes it through a RESO-Platinum-certified Web API 2.0 / OData 4.0 endpoint and a legacy RETS 1.8 endpoint, plus a bidirectional Direct Web API into the Matrix MLS CRM and a Participant Reporting API used to prove broker relationships back to the MLSs.

Generated by API Evangelist (https://apievangelist.com) on 2026-07-26 from the provider's public surface. Trestle publishes no /llms.txt of its own (HTTP 404 on trestle-documentation.corelogic.com/llms.txt and www.cotality.com/llms.txt).

## Read this first — the access gate

Trestle is fully documented and effectively uncallable without a contract. The documentation portal is public and needs no login, the OData service document answers anonymously with a 200, and the OAuth2 flow, quotas and every OData query convention are published openly. But the $metadata document and every entity set return 401. Credentials are issued only after a developer registers a Technology Provider or Broker account, requests a connection to each individual multiple listing organization, and completes an e-signed data licence contract that all parties sign — a contract most MLSs will only ratify if a licensed broker or agent sponsors it or the technology provider files periodic participant reports. There is no sandbox, no trial key and no public sample credential. Certification is not reachability.

## APIs

- [Trestle RESO Web API](https://trestle-documentation.corelogic.com/webapi.html): RESO Web API 2.0 / OData 4.0 at https://api.cotality.com/trestle/odata. 18 entity sets. OAuth2 client_credentials, scope=api, 8-hour Bearer token.
- [Trestle RETS](https://trestle-documentation.corelogic.com/rets.html): Legacy RETS 1.8 at https://api.cotality.com/trestle/rets. Session-less; HTTP Basic or OAuth2 with scope=rets. Digest auth explicitly unsupported.
- [Trestle Direct Web API](https://trestle-documentation.corelogic.com/direct-webapi-crm-reference.html): Bidirectional OData into the Matrix MLS database — Contacts, EmailHistory, Lists, PortalContents, SavedSearches, UserRegistry, DashboardAPI. OpenID Connect / Clareity SSO / HTTP Basic.
- [Trestle Participant Reporting API](https://trestle-documentation.corelogic.com/participant-reporting-api.html): POST and GET /trestle/report/TpParticipantReport — how technology providers evidence broker contracts to each MLS.

## Specs and machine-readable artifacts

- [OData service document](https://api.cotality.com/trestle/odata): anonymous, 200 — enumerates the 18 entity sets. Saved at openapi/trestle-odata-service-document.json.
- [OData $metadata (CSDL)](https://api.cotality.com/trestle/odata/$metadata): 401 — the real machine-readable contract is gated.
- [OpenID Connect discovery](https://api.cotality.com/trestle/oidc/.well-known/openid-configuration): anonymous, 200 — scopes, grants, endpoints. Saved at well-known/trestle-openid-configuration.json.
- [Postman collection](https://trestle-documentation.corelogic.com/samples/postman/trestle-webapi.json): "Trestle WebAPI Demonstration", 15 requests and 30 saved examples. Saved at postman/trestle-webapi.postman_collection.json.
- No OpenAPI or Swagger document exists anywhere on the Trestle or Cotality surface.
- No AsyncAPI, no webhooks, no events. Change capture is pull-based OData replication.
- No MCP server for Trestle. (Cotality operates one for a different product line: https://www.cotality.com/platforms/mcp-server)

## Resources (RESO Data Dictionary 2.0)

Property (761 fields, key ListingKey), Building (328), CustomProperty (144), Member (94), Office (82), Media (58), PropertyUnitTypes (54), Teams (50), OpenHouse (49), PropertyRooms (41), HistoryTransactional (31), TeamMembers (31), Field (15), Lookup (15), Model (8), plus DataSystem and Enumeration in the service document. Field-level metadata and enumerations are published anonymously at https://api.cotality.com/trestle/Documentation/MetaData/Resource/ and https://api.cotality.com/trestle/Documentation/MetaData/Enums.

## Conventions

- Pagination: OData $top (max 1000; 300,000 for key-only InKeyIndex queries) + $skip, or follow @odata.nextLink.
- Query: $filter, $select, $count, $expand, $apply=groupby() (partial).
- Trestle extensions: Replication=true (bulk endpoint, >1,000,000 records) and PrettyEnums=true (human-readable enum values).
- Change capture: filter on ModificationTimestamp (records) and PhotosChangeTimestamp (media, lives on Property). Deletions require periodic key-list reconciliation.
- Quotas: 7,200 queries/hour and 180/minute for the Web API; 18,000/hour and 480/minute for public media URLs. Headers Minute-Quota-Limit, Hour-Quota-Limit, Hour-Quota-ResetTime, QuotaType — returned even on a 401.
- Errors: OData error objects. 400 bad credentials/connection type, 401 no valid token, 404 not found or not licensed, 429 quota exceeded, 500 server error, 504 gateway timeout. Not RFC 9457.
- No idempotency key. No request-id header. No Sunset/Deprecation headers.
